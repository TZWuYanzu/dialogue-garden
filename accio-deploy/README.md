# Accio 户外博主运营团队 — 部署指南

## 团队概览

5 人 AI Agent 运营团队，专为户外赛道（越野跑/徒步/露营）小红书博主设计。

| 角色 | 文件 | 推荐模型 | 职责 |
|------|------|---------|------|
| Team Leader | `01-team-leader.md` | Orbit 极致 | 任务拆解、调度协作、最终决策 |
| 数据分析专家 | `02-data-analyst.md` | Orbit 专业 | 数据录入管理、竞品分析、趋势预判 |
| 内容产出专家 | `03-content-expert.md` | Orbit 极致 | 封面、标题、文案、拍摄指导 |
| 复盘专家 | `04-review-expert.md` | DeepSeek V4 Flash | 发布后数据分析、A/B 测试、方法论沉淀 |
| 选题排期专家 | `05-topic-scheduler.md` | Orbit 专业 | 选题库管理、内容日历、发布节奏 |

## 在新电脑上部署

### 前置条件

1. 安装 [Accio](https://accio.so) 桌面端
2. 登录你的 Accio 账号

### 部署步骤

#### 第一步：创建 Agent

在 Accio 中依次创建 5 个 Agent：

1. 点击「新建 Agent」
2. 填写名称（如「小红书运营专家」「户外赛道数据分析专家」等）
3. 选择推荐模型（见上表）
4. 将 `prompts/` 目录下对应的 `.md` 文件内容，粘贴到 Agent 的**提示词/身份设定**区域

#### 第二步：配置 Team Leader

Team Leader 需要能调用其他 4 个 Agent：

1. 打开 Team Leader Agent 的设置
2. 在「技能」或「子 Agent」配置中，关联其他 4 个 Agent
3. 确保 Team Leader 可以通过 `sessions_spawn` 或类似机制派遣任务

#### 第三步：设置用户信息

在 Team Leader 的用户信息/上下文中配置：

```
用户：金哥
地点：杭州
身份：想成为户外博主的越野跑者
账号阶段：起步期
主要赛道：越野跑、徒步、户外
```

#### 第四步：验证部署

用以下 3 个场景测试团队是否正常工作：

**测试 1 — 内容产出**
> "我下周去莫干山徒步，帮我出一套内容方案"

预期：Team Leader 拆解任务 → 数据分析专家分析相关爆款 → 内容产出专家产出封面+标题+文案

**测试 2 — 数据复盘**
> "这条笔记发了 3 天，数据是：曝光 5000，阅读 800，点赞 120，收藏 80，评论 15，帮我复盘"

预期：Team Leader 派遣复盘专家 → 输出结构化复盘报告

**测试 3 — 选题排期**
> "帮我规划下个月的内容日历"

预期：Team Leader 协调数据分析专家和选题排期专家 → 产出月度日历

## 数据录入工作流

本团队**不依赖爬虫**采集数据。数据通过以下方式获取：

1. **手动浏览**：日常刷小红书时，按 `templates/data-input-*.md` 格式记录感兴趣的博主和笔记
2. **第三方平台**：使用千瓜数据、新红数据等合规平台导出报表
3. **截图提取**：将小红书后台数据截图发给 Agent，由数据分析专家提取关键数据
4. **已有数据**：项目中已采集的约 200 条帖子数据可直接查询分析

### 日常操作建议

- 每天刷小红书时，遇到好的博主/笔记顺手按模板记录 2-3 条
- 每周整理一次，批量提交给数据分析专家
- 发布笔记后 7 天，按 `review-input.md` 模板提交数据给复盘专家
- 每月初让选题排期专家产出下月日历

## 与原版的改动说明

相比原始 Agent 提示词，本版本做了以下优化：

| 改动 | 原因 |
|------|------|
| 数据分析专家：删除爬虫依赖，改为手动录入 + 分析 | 爬虫导致账号被官方警告 |
| 选题排期专家：从 1 行描述扩展为完整提示词 | 原版功能缺失 |
| 复盘专家：新增结构化数据录入模板 | 降低用户提交数据的门槛 |
| 内容产出专家：新增季节性内容模板 | 提供更具体的创作指导 |
| Team Leader：新增任务信封格式、爆款公式手册管理 | 规范跨 Agent 协作 |
| 全部角色：SOP 中统一引用任务信封格式 | 确保信息传递不丢失上下文 |

## 注意事项

- 模型选择影响效果：Team Leader 和内容产出专家建议用最强模型，复盘专家可用性价比模型
- 第一次使用时，建议先用测试场景跑通流程，再投入实际运营
- 模板文件是参考格式，实际使用中 Agent 会主动引导你按格式输入
