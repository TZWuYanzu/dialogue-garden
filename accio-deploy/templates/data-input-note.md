# 笔记数据录入模板

记录单条小红书笔记的完整数据，用于爆款分析和内容复盘。

---

```
【笔记数据】
━━━━━━━━ 基本信息 ━━━━━━━━
笔记链接/ID：
博主昵称：
标题：（原文逐字）
内容类型：(图文 / 视频)
发布时间：YYYY/MM/DD HH:MM

━━━━━━━━ 封面信息 ━━━━━━━━
封面类型：(大字报 / 人景合一 / 极致风景 / 装备特写 / 拼图对比 / 表情管理 / 其他)
封面文字：（如有，逐字记录）
图片数量：
视频时长：（如为图文标注"无"）

━━━━━━━━ 互动数据 ━━━━━━━━
点赞数：
收藏数：
评论数：
分享数：

━━━━━━━━ 内容详情 ━━━━━━━━
正文摘要/全文：

话题标签：
#
#
#

━━━━━━━━ 评论区 ━━━━━━━━
前 3 条热评：
1.
2.
3.

━━━━━━━━ 元信息 ━━━━━━━━
数据采集时间：YYYY/MM/DD
数据来源：(手动浏览 / 千瓜 / 新红 / 截图)
来源关键词：（如通过搜索发现，记录搜索词）
备注：
```

---

## 填写说明

- **标题**：必须逐字记录原标题，包括 emoji，用于标题公式分析
- **互动数据**：写数字，`15000` 而非 `1.5万`
- **正文**：干货类笔记建议全文录入；情绪类笔记可写摘要
- **热评**：记录点赞最高的 3 条评论，这些反映用户真实需求
- **来源关键词**：标注搜索词便于后续分析该关键词的爆款规律
