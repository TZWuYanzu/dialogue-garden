# 选题卡片模板

每个选题入库时填写此卡片，由选题排期专家评估打分后纳入排期。

---

```
【选题卡片】
━━━━━━━━━━━━━━━━━━━━━━
选题名称：
选题类型：(常青 / 季节 / 热点 / 系列 / 互动)
内容类型：(干货 / 情绪 / 种草)
━━━━━━━━━━━━━━━━━━━━━━

【评估打分】（各项 0-5 分）
  搜索需求：  /5  —（关键词搜索量、竞争度）
  人设契合：  /5  —（是否符合账号定位）
  创作可行：  /5  —（素材是否到位、拍摄难度）
  爆款潜力：  /5  —（参考数据分析和爆款规律）
  ────────────────
  综合评分：  /5  （= 搜索×0.25 + 人设×0.30 + 可行×0.20 + 爆款×0.25）

【排期判定】
  ≥4.0 → 优先排期（本周/下周发）
  3.0-3.9 → 本月备选池
  <3.0 → 暂不排期，存入灵感库

━━━━━━━━━━━━━━━━━━━━━━
时效窗口：(不限 / 本周 / 本月 / YYYY/MM/DD 前)
所需素材：(已有 / 待拍 / 待收集)
对标参考：(博主名 + 笔记标题/链接)
关联系列：(如属于某系列，填系列名)
创意简述：（2-3 句话描述这条内容的核心想法和差异化角度）
━━━━━━━━━━━━━━━━━━━━━━

【生命周期】
状态：灵感 / 待排期 / 已排期(MM/DD) / 已发布 / 已复盘
排期日期：
发布日期：
复盘结果：(✅已验证爆款 / ⭕表现正常 / ❌表现不佳)
复盘摘要：
━━━━━━━━━━━━━━━━━━━━━━
```

---

## 使用说明

- **选题类型**参考：
  - 常青：不受时间影响，长期有搜索价值（如"新手装备清单"）
  - 季节：与时令/天气/节假日绑定（如"秋天赏红叶路线"）
  - 热点：追踪当前趋势窗口期（如"Hyrox 热潮"）
  - 系列：构建内容 IP（如"30天跑山日记"）
  - 互动：引发讨论和参与（如"你的第一双越野鞋"）
- **综合评分**由选题排期专家计算，不需要手动算
- **复盘结果**在笔记发布并经复盘专家分析后填写，完成闭环
