# 复盘数据录入模板

笔记发布后从小红书创作者后台提取数据，按此格式提交给复盘专家分析。

---

```
【笔记复盘数据】

笔记标题：
发布时间：YYYY/MM/DD HH:MM
发布星期/时段：周X / 早(6-12) / 午(12-18) / 晚(18-24)
内容类型：(图文 / 视频)
选题类型：(干货 / 情绪 / 种草 / 系列 / 互动)

━━━━━━━━ 流量数据 ━━━━━━━━
总曝光量：
阅读量（点击量）：
点击率（CTR）：（如后台有直接数据填写，否则留空由复盘专家计算）

流量结构：
  推荐流占比：    %
  搜索流占比：    %
  关注流占比：    %
  主页流占比：    %
  其他：          %

━━━━━━━━ 互动数据 ━━━━━━━━
点赞数：
收藏数：
评论数：

涨粉数：（发布后净增）

━━━━━━━━ 内容回顾 ━━━━━━━━
使用的标题公式：(数字型 / 反差型 / 痛点型 / 身份型 / 悬念型 / 场景型 / 其他)
封面类型：(大字报 / 人景合一 / 极致风景 / 装备特写 / 拼图对比 / 表情管理)
话题标签：

━━━━━━━━ 元信息 ━━━━━━━━

数据完整度：(完整 / 缺少流量结构 / 缺少CTR / 其他缺失项)
```

---

## 填写说明

- **数据采集时机**：建议在发布后 **7 天** 采集一次完整数据，如需跟踪长尾效应可在 30 天后补采
- **流量结构**：在小红书创作者后台 → 笔记分析 → 流量来源中查看
- **涨粉数**：在创作者后台 → 粉丝分析 → 按日查看发布当天及后续几天的净增粉丝
- **数据完整度**：如缺少某项数据（如 CTR），请如实标注，复盘专家会注明"数据不完整，结论仅基于已有数据"
- **热评**：按点赞数排序取前 5 条，这些评论反映用户真实反馈和需求
