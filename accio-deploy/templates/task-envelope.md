# 任务信封模板

Team Leader 派遣子 Agent 时的标准格式。**每次派遣必须使用此格式**，不得直接转发用户原话。

---

```
===== 任务信封 =====
【任务ID】YYYYMMDD-序号（如 20260612-01）
【派遣对象】数据分析专家 / 内容产出专家 / 复盘专家 / 选题排期专家
【任务类型】数据分析 / 内容产出 / 数据复盘 / 选题排期
【优先级】P0 紧急 / P1 本周 / P2 本月
【任务目标】一句话描述本次任务要解决什么问题
【任务背景】
  - 上下文：（之前做过的相关工作、其他专家已产出的报告摘要）
  - 账号当前状态：粉丝 X，近期发了 Y 篇，平均互动 Z
  - 用户原始需求：（引用用户原话）
【具体要求】
  1. ...
  2. ...
  3. ...
【输出格式】Markdown / 表格 / 选题卡片 / 物料包
===== 信封结束 =====
```

---

## 使用说明

- **任务 ID**：日期 + 当天序号，便于追溯
- **优先级定义**：
  - P0：今天必须完成（热点窗口、紧急复盘）
  - P1：本周内完成（常规排期、内容产出）
  - P2：本月内完成（趋势分析、方法论沉淀）
- **任务背景**：必须包含足够上下文，子 Agent 不应该需要反问才能开始工作
- **输出格式**：明确告知子 Agent 交付物的形式，避免格式返工

## 示例

```
===== 任务信封 =====
【任务ID】20260612-01
【派遣对象】数据分析专家
【任务类型】数据分析
【优先级】P1 本周
【任务目标】分析已有数据中徒步赛道 TOP10 爆款笔记的共性特征
【任务背景】
  - 上下文：数据库中已有约 200 条徒步+越野跑帖子数据
  - 账号当前状态：粉丝 500，已发 8 篇，平均互动 50
  - 用户原始需求："帮我看看别人的爆款都有什么共同点"
【具体要求】
  1. 按互动量（点赞+收藏+评论）排序，取 TOP 10
  2. 分析标题公式、封面类型、内容结构的共性
  3. 提炼 3-5 条可直接复用的方法论
【输出格式】Markdown 报告
===== 信封结束 =====
```
