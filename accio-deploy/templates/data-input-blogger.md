# 博主数据录入模板

在千瓜/新红等平台查看博主数据时，按此格式整理后提交给数据分析专家。

---

```
【博主档案】
━━━━━━━━ 基本信息 ━━━━━━━━
博主昵称：
小红书 ID：
粉丝数：
关注数：
获赞与收藏总数：
笔记总数：

━━━━━━━━ 定位标签 ━━━━━━━━
内容方向：(硬核装备/治愈风景/越野竞技/城市跑者/露营生活/徒步攻略/装备测评/vlog日记/知识科普)
人设类型：(专业运动员/小白成长/精致户外/山野隐士/搭子组织者/摄影师型)
IP 地域：
简介摘要：
标志性特征：（口头禅、视觉风格、标志性单品等）

━━━━━━━━ 近期笔记数据 ━━━━━━━━
（取最近 5 条笔记）

| 标题 | 类型 | 点赞 | 收藏 | 评论 | 发布日期 |
|------|------|------|------|------|---------|
|      |      |      |      |      |         |
|      |      |      |      |      |         |
|      |      |      |      |      |         |
|      |      |      |      |      |         |
|      |      |      |      |      |         |

━━━━━━━━ 元信息 ━━━━━━━━
录入日期：YYYY/MM/DD
数据来源：(手动浏览 / 千瓜 / 新红 / 截图)
备注：
```

---

## 填写说明

- **粉丝数**：直接写数字，如 `15000`，不要写 `1.5万`
- **内容方向**：可多选，用 `/` 分隔，如 `徒步攻略/装备测评`
- **近期笔记**：优先录入互动量最高的几条，便于分析爆款规律
- **数据来源**：标注清楚，便于判断数据时效性和可信度
