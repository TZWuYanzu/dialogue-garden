## Part 2: 未来规划

### Phase 1: 数据补全（夯实基础）

> 目标：拿到精确的博主分层数据，为运营决策提供真实依据

- [ ] 跑通 `fetch_profiles.py`，补全 hiking 和 trail_running 的博主 profile 数据
- [ ] 用精确粉丝数重新运行 `classify_bloggers.py`，替换掉估算版本
- [ ] 补采越野跑领域的评论数据
- [ ] 扩展关键词覆盖：露营、骑行、滑雪等阿K关注的户外领域
- [ ] 达成 120 位博主的筛选目标（每层 20 人 x 3 个粉丝层级 x 2 个领域）

### Phase 2: Agent 系统上线（让工具跑起来）

> 目标：在本地或 Accio 上跑通 AI 运营团队，能实际辅助内容产出

- [ ] 端到端测试 `agents/` CLI 系统，修复发现的问题
- [ ] 提供 `.env.example` 和 setup 脚本，降低部署门槛
- [ ] 初始化知识库：录入前期采集数据中提炼的爆款公式（标题模式、封面风格、互动规律）
- [ ] 在 Accio 平台部署 5 个 Agent，跑通 3 个验证场景
- [ ] 对齐所有角色提示词的调性，确保统一为"运营搭子"风格

### Phase 3: 内容产出闭环（从数据到发布）

> 目标：形成"数据分析 → 选题 → 内容产出 → 发布 → 复盘"完整工作流

- [ ] 建立周度运营节奏：每周 Agent 自动产出下周内容日历
- [ ] 复盘流程跑通：每条笔记发布 7 天后，提交数据给复盘专家，沉淀方法论
- [ ] 积累 10+ 条爆款公式，验证哪些内容模式在户外赛道有效
- [ ] 选题库达到 30+ 待用选题储备

### Phase 4: 增长与迭代（长期）

> 目标：账号从起步期进入成长期，粉丝破 2000

- [ ] 基于复盘数据，迭代内容策略（什么类型的帖子互动率最高）
- [ ] 探索合作博主互推、评论区互动等增长手段
- [ ] 考虑增加视频内容的辅助能力（脚本生成、封面设计指导）
- [ ] 评估是否需要接入更多数据源（千瓜、新红等第三方平台）
- [ ] Agent 系统持续优化：对话记忆、多轮任务跟踪、成本控制
